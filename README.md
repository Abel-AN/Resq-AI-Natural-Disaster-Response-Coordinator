# Resq-AI

AI-powered Disaster Response Coordination System designed to monitor natural disaster risks and provide intelligent emergency assistance through a modern desktop application.


#  Features

  * Real-time Flood Risk Detection
  * Heatwave Monitoring System
  * Earthquake Activity Monitoring
  * AI Disaster Assistant Chatbot
  * Interactive Disaster Dashboard
  * Dark / Light Mode Support
  * Location-based Disaster Analysis
  * Modern Desktop Interface
  * Fast Executable Application (.exe)


# About The Project

Resq-AI is a disaster response coordination application built to help users monitor environmental risks and receive intelligent disaster-related assistance in real time.

The system combines:

  * Weather analysis
  * Earthquake monitoring
  * AI chatbot assistance
  * Interactive risk visualization into one professional desktop application.



# Technologies Used

  * Python
  * CustomTkinter
  * OpenWeatherMap API
  * USGS Earthquake API
  * JSON Knowledge Base
  * Requests Library
